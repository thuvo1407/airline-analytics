Customer: one real person with one customer_id in the customer master.
Golden record: The single trusted row per customer in dw.dim_customer.
Record linkage: Deciding that records from different systems describe the same customer.
Match rule: One test used to link records (i.e "same email"), every link stores its rule.
Duplicate profile: Two loyalty members that can be linked to the same customer.
Anonymous session: A web visit with no logged-in customer.
